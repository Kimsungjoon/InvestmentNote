| 유형 | 종목 | 쉽게 |
|------|------|------|
| **떨어지는 칼 (낙폭 과대)** | PINS·VEEV·MELI·TOST·NTNX·DASH | 고점 대비 -26%~-39% 급락. 바닥 확인 전이라 위험 |
| **이미 비쌈 (고평가) + 손익비 부족** | ADP·PH·FAST·HWM·CSX·FTNT | 추세는 좋아도 값이 부담 + RR 1 근처 |
| **목표가 근접 (먹을 폭 적음)** | EBAY·ABNB·INCY·NBIX | 목표가와 현재가가 거의 붙음(RR 0.3~0.9) |

> 참고 기업 한 줄: **PINS**=이미지 소셜·광고 / **VEEV**=제약사 전용 클라우드 / **MELI**=중남미 아마존(이커머스+핀테크) / **TOST**=식당 결제 단말·SW / **NTNX**=데이터센터 가상화 SW / **DASH**=미국 음식배달 / **ADP**=급여·인사 아웃소싱 / **PH**=산업용 유압부품 / **FAST**=산업용 부품 유통 / **HWM**=항공기 엔진부품 / **CSX**=미 동부 철도물류 / **FTNT**=사이버보안(방화벽) / **EBAY**=온라인 중고·수집품 마켓 / **ABNB**=숙박공유 / **INCY**·**NBIX**=바이오 신약.

| 용어 | 쉽게 말하면 |
|------|-------------|
| **QQQ / 50일선(50MA)** | QQQ=미국 기술주 100개 대표지수(시장 온도계). 50일선=최근 50일 평균가, 위면 강세·아래면 약세. |
| **레짐(🟢🟡🔴)** | 지금이 살 때인지 신호등. 🟢 사도 됨 / 🟡 조심(소량만) / 🔴 기다리기. |
| **정배열** | 단기·중기·장기 평균선이 위→아래로 가지런한 건강한 상승 추세. |
| **손익비(RR)** | 벌 수 있는 돈 ÷ 잃을 수 있는 돈. 2 이상이면 매수 검토 기준 충족. |
| **PEG / PER** | PER=주가가 이익의 몇 배. PEG=그걸 성장속도로 나눈 값(낮을수록 저평가). |
| **매수가·손절가·목표가** | 매수가=들어갈 가격 / 손절가=깨지면 파는 방어선 / 목표가=이익 실현해 파는 가격. |
